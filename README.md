## 📂 Projects

### 🏨 [Okoto Travels](https://github.com/auwalcodes2007/Freelance-Portfolio/blob/main/Okoto%20Travels)
Full-stack Flask web application for a travel and tours agency.
Includes dynamic templates, route handling, and a mobile-friendly
interface built for a real client use case.
**Tools:** Python, Flask, Jinja2, HTML/CSS

---

### 🔹 [Project 1 — Book Scraper](https://github.com/auwalcodes2007/Freelance-Portfolio/blob/main/project-1-scraper)
Scrapes the title and price of 1000 books across 50 pages from a
live website and exports the data to a clean Excel file automatically.
**Tools:** Python, BeautifulSoup4, Requests, OpenPyXL

---

### 🔹 [Project 2 — Excel Data Cleaner](https://github.com/auwalcodes2007/Freelance-Portfolio/blob/main/project-2-excel)
Takes a messy CSV file with duplicates, bad formatting, missing
fields, and invalid data — and outputs a clean, styled Excel file
ready for reporting or importing into business systems.
**Tools:** Python, Pandas, OpenPyXL

---

### 🔹 [Project 3 — Email Automation](https://github.com/auwalcodes2007/Freelance-Portfolio/blob/main/project-3-automation)
Reads a contact list from Excel and sends each person a personalized
email automatically — no copy-pasting, no manual work.
**Tools:** Python, smtplib, OpenPyXL, python-dotenv
